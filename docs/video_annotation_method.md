# Video Annotation Method

This is the repeatable method I use for practice and evaluation tasks.

1. Read the instruction and rubric before watching the clip.
2. Watch once without annotating to understand the complete sequence.
3. Watch again and identify candidate action boundaries.
4. Define each event using only observable evidence.
5. Mark start/end timestamps at the rubric-defined state transition.
6. Record actor, action, object, interaction, and end state.
7. Evaluate whether the clip fully, partially, or unsuccessfully fulfills the instruction.
8. Add a short reviewer note only when it clarifies an edge case.
9. Perform an independent second pass for consistency and timestamp drift.
10. Flag ambiguous cases instead of inventing intent.

The goal is reproducibility: another reviewer using the same rubric should reach the same decision.
